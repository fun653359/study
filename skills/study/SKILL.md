# 학습 세션

기록 위치는 `~/study/<주제>/`이다(주제 이름의 공백은 `-`로 바꾼다). 지난 학습에 대한 기억은 이 파일들에만 있다. 세션을 시작할 때마다 반드시 다시 읽고, 진행하면서 그때그때 바로 쓴다. 세션이 갑자기 끊겨도 기록이 남아야 한다.

인수: `$ARGUMENTS`

## 파일 구조

```
~/study/<주제>/
├── curriculum.md   # 목표, 수준, 차시 목록, 진도
├── lessons/NN.md   # 차시별 수업 기록 (다룬 내용, 내 질문, 헷갈린 점)
├── quiz/NN.md      # 차시별 문제, 내 답, 채점
└── weak.md         # 약점 개념과 복습 일정
```

### curriculum.md
```markdown
# <주제>
- 목표: <왜, 어디에 쓰려고 배우는지>
- 수준: <시작 시점에 이미 알던 것>
- 자료: <교재/강의, 없으면 "없음">
- 기한: YYYY-MM-DD (<무엇의 기한: 시험일, 프로젝트 시작 등>) | 없음
- 시작: YYYY-MM-DD
- 마지막 학습: YYYY-MM-DD

## 차시
### 1부. <부 제목>
- [x] 01. <제목> — <한 줄 범위>
- [ ] 02. <제목> — <한 줄 범위>
- [ ] 02-1. (보충) <제목> — <한 줄 범위>
### 2부. <부 제목>
- [ ] 03. <제목> — <한 줄 범위>
```
체크되지 않은 첫 항목이 다음 차시다. 사용자가 이 파일을 직접 고쳤을 수 있으니 항상 파일에 적힌 그대로 따른다. 차시가 많으면 `###` 제목으로 부를 나눈다.

### 진도
진도는 보여줄 때마다 `curriculum.md`의 체크박스에서 새로 계산한다. 파일에 숫자로 적어 두지 않는다(적어 두면 체크와 어긋난다).
- 전체: 완료/전체 차시와 퍼센트. 보충 차시도 한 차시로 센다. 퍼센트는 정수로 반올림한다.
- 부별: `###` 제목이 있으면 부마다 완료/전체와 퍼센트. 지금 진행 중인 부를 먼저 보여준다.
- 기한이 있으면 페이스도 계산한다.
  - 예정 진도 = (오늘 − 시작) / (기한 − 시작). 실제 진도와 비교해 몇 %p 앞섰는지 뒤처졌는지.
  - 필요 속도 = 남은 차시 / 남은 날. 하루 1차시 미만이면 주 단위로 바꿔 말한다.
  - 기한이 지났으면 지났다고 말하고 새 기한을 물어본다.

```
진도 4/50 (8%) · 2부 1/20 (5%) · 1부 14/14 (100%)
기한 2027-05-30 (리눅스마스터 1급 1차)까지 194일 · 예정 6% → 2%p 앞섬 · 필요 속도 주 2차시
```

### lessons/NN.md
```markdown
# NN. <제목> (YYYY-MM-DD)
상태: 수업 중 | 문제 중 | 복습 중 | 완료

## 다룬 내용
- <설명한 핵심 개념, 예시>

## 내가 한 질문
- Q: <질문> → <답 요약>

## 헷갈린 점
- <무엇을 어떻게 잘못 이해했는지>
```

### quiz/NN.md
```markdown
# NN. 문제 (YYYY-MM-DD)
## 1. <문제>
- 근거: <lessons/NN.md의 어느 내용 / 헷갈린 점>
- 내 답: <사용자 답 요약>
- 결과: ✅ | 🔺 | ❌
- 해설: <한두 줄>

점수: <합계>/<문제 수>
```
결과는 ✅(혼자 맞힘) 1점, 🔺(힌트를 받고 맞혔거나 일부만 맞힘) 0.5점, ❌ 0점이다. 점수와 마무리의 60% 기준 모두 이 합계로 계산한다.

### weak.md
```markdown
| 개념 | 출처 | 틀린 이유 | 단계 | 복습 시점(완료 차시 수) |
|---|---|---|---|---|
```
- "완료 차시 수"는 curriculum.md에서 `[x]`인 항목 개수다.
- 새 약점은 단계 0, 복습 시점은 현재 완료 차시 수 + 1.
- 복습에서 맞히면 단계 +1, 복습 시점은 현재 완료 차시 수 + (단계 1이면 3, 단계 2면 7). 단계 3이 되면 표 아래 `## 졸업` 목록으로 옮긴다.
- 복습에서 틀리면 단계 0, 복습 시점은 현재 완료 차시 수 + 1. 틀린 이유를 갱신한다.

## 인수에 따른 동작

- `new <주제>`: 새 주제를 시작한다(아래 "새 주제").
- `<주제>`: 그 주제를 이어서 한다.
- `status`: 수업 없이 주제별 진도("진도" 형식의 퍼센트와 기한 페이스), 다음 차시, 복습 대기 중인 약점만 보여준다.
- 인수 없음: `~/study` 아래 주제가 하나면 그것을 이어 한다. 여러 개면 마지막 학습일이 가장 최근인 주제를 제안하고 확인받는다. 하나도 없으면 무엇을 배우고 싶은지 묻고 "새 주제"로 간다.
- 이름에 맞는 주제 폴더가 없으면 새로 만들지 묻는다.

## 새 주제

1. 아래를 한 번에 묶어서 묻는다.
   - 목표: 왜 배우는지, 어디에 쓸 건지
   - 현재 수준: 이미 아는 것, 모르는 것
   - 자료: 따라갈 교재나 강의가 있는지(목차를 주면 그 순서에 맞춘다)
   - 차시 분량: 한 번에 어느 정도 할지
   - 기한: 언제까지 끝내야 하는지(시험일, 프로젝트 시작일 등). 없어도 된다
2. 답에 맞춰 커리큘럼 초안을 보여준다. 한 차시는 핵심 개념 하나이고, 앞 차시가 뒤 차시의 전제가 되도록 순서를 짠다. 이미 아는 것은 빼거나 짧게 한다. 기한이 있으면 초안과 함께 필요 속도(주 몇 차시)를 보여주고, 무리라면 덜 중요한 차시를 합치거나 빼는 안을 같이 낸다.
3. 사용자가 고치고 싶은 부분을 반영해서 확정한 뒤 `curriculum.md`와 빈 `weak.md`를 만든다.
4. 바로 1차시를 시작할지 묻는다.

## 한 세션 = 한 차시

### 0. 이어 받기
- `curriculum.md`, 직전 차시의 `lessons`, `quiz`, `weak.md`를 읽는다.
- `curriculum.md`에 `기한:` 줄이 없으면(기한을 묻기 전에 만든 주제) 시작하기 전에 한 번 묻고 `자료:` 줄 아래에 적는다. 없다고 하면 "없음"으로 적어서 다시 묻지 않는다.
- 다음 차시의 `lessons/NN.md`가 이미 있고 상태가 "완료"가 아니면, 그 상태의 단계부터 이어 한다. "문제 중"이면 `quiz/NN.md`에서 결과가 비어 있는 문제부터 다시 낸다.
- 두세 줄로 시작한다: 지난번에 무엇을 했고 어디서 막혔는지, 오늘 무엇을 하는지. 지난번 헷갈린 점이 오늘 내용과 이어지면 짚고 간다.
- 파일에 없는 일은 기억하는 척하지 않는다.

### 1. 수업
- 설명을 시작하기 전에 가장 먼저 `lessons/NN.md`를 "상태: 수업 중"으로 만든다. 플러그인은 이 상태 줄이 "완료"가 아닌 동안 추천 문구(다음 입력 예측)를 숨겨서 정답이 미리 보이지 않게 한다.
- 이번 차시 범위만 다룬다. 다음 차시 내용을 미리 끌어오지 않는다.
- 작은 단위로 나눠서 설명하고, 한 덩어리마다 사용자가 반응하거나 질문할 여지를 둔다. 긴 강의를 한 번에 쏟아내지 않는다.
- 이해를 확인하는 질문은 방금 설명한 내용에 대해서, 사용자의 반응을 보고 필요할 때만 한다. 형식적으로 끼워 넣는 질문은 하지 않는다.
- 사용자 질문이 범위를 벗어나도 답한다. 깊이 다룰 내용이면 몇 차시에서 다룬다고 알려준다.
- 사용자가 질문하거나 헷갈려 하면 그 즉시 `lessons/NN.md`에 기록한다. "다룬 내용"도 설명할 때마다 채운다.
- 범위를 다 다뤘으면 문제로 넘어갈지 묻고, 상태를 "문제 중"으로 바꾼다.

### 2. 문제
- 3~5문제를 낸다. 근거는 이번 차시 `lessons/NN.md`에 기록된 내용과 헷갈린 점뿐이다. 수업에서 다루지 않은 것은 내지 않는다.
- 헷갈린 점이 있었다면 최소 한 문제는 그 부분을 다룬다.
- 단순 암기보다 자기 말로 설명하기, 적용하기, 비교하기 문제를 우선한다.
- 한 번에 한 문제씩 낸다. 문제를 보여주기 전에 먼저 `quiz/NN.md`에 문제와 근거를 적어 둔다. 그래야 세션이 중간에 끊겨도 어떤 문제를 냈는지 남는다.
- 답을 받으면 채점하고 해설한 뒤, 같은 항목에 내 답, 결과, 해설을 바로 채운다. 틀리면 정답을 바로 주지 말고 힌트를 한 번 준다. 그래도 틀리면 해설한다. ❌나 🔺인 개념은 `weak.md`에 추가한다.
- 다 끝나면 상태를 "복습 중"으로 바꾼다.

### 3. 복습
- `weak.md`에서 복습 시점이 된 항목(복습 시점 ≤ 현재 완료 차시 수)을 최대 3개 고른다. 이번 차시에서 새로 생긴 약점은 제외한다. 없으면 복습이 없다고 말하고 넘어간다.
- 출처 차시에서 무엇을 왜 틀렸는지에 근거해서 내되, 같은 문제를 그대로 반복하지 않고 각도를 바꾼다.
- 결과에 따라 `weak.md`의 단계와 복습 시점을 갱신한다.

### 4. 마무리
- 문제 점수가 60% 미만이거나 핵심 개념을 이해하지 못한 것이 보이면, 바로 다음에 보충 차시(NN-1)를 넣자고 제안한다. 동의하면 `curriculum.md`에 추가한다.
- 이번 차시를 `[x]`로 체크하고, 마지막 학습 날짜와 `lessons/NN.md` 상태("완료")를 갱신한다.
- 오늘 배운 것 한두 줄, 남은 약점, "진도" 형식의 진도(기한이 있으면 페이스까지), 다음 차시 예고로 끝낸다.

## 중간에 그만둘 때
사용자가 그만하자고 하면 지금까지 내용을 저장하고, 상태와 함께 어디까지 했는지 `lessons/NN.md`에 한 줄 남긴다. 차시는 체크하지 않는다. 다음 세션에서 그 지점부터 이어 한다.
